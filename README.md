# 大肥鱼长毛象 bot

部署在 Mastodon 的大肥鱼 bot：自己发 toot、自己回嘟文，带一个小本本，记下聊过的人和话。

`dsh-mastodon-toot` · DeepSeek Harness 插件

> 这是从一套跑了几个月的自用脚本（Python）重写来的。重写的原因很简单：公共插件不该要求用户装 Python、配另一套 key，也不该把规则散在命令行参数里。

## 现在能做什么（v0.3.13）

- **接入**：填实例地址 + 访问令牌，测试连接；支持 HTTP 代理（CONNECT 隧道），直连能通就不用填。
- **设置页**：DSH → 设置 → 长毛象，分成五个页签：连接 / 回复 / 发帖 / 小本本 / 高级与日志。
- **回了谁一定回**：别人 @ 我、回我的嘟文，一律必回——不看冷却、不看夜里（人家当面说话，不应声才是不礼貌），额度按倍数放宽防刷屏；主人自己发的帖就算没 @ 我也接一句。被额度挡住的不会丢：游标只走到「真处理完」那条，下轮接着来（同一条连挂 3 次才跳过）。三项都在设置页「回复 → 通用」里可关：**@ 必回**（总开关）、**必回额度倍数**（默认 2）、**主人发帖也回**；关掉「@ 必回」就退回按分组冷却/夜间的老规矩，设置页显示的也就是实际在跑的。
- **分组互动**：主人 / 好友（互关）/ 其他人 三组分开设置——回 @、回时间线、每日额度、每串上限、冷却分钟各管各的，**不掷骰子**。@ 我和时间线分开算；夜里 23–08 只回主人；每条「回了 / 没回（为什么）」都进小本本。
- **发帖管线**：素材 = 天气 / RSS 新闻 / GitHub 新项目 / 博客旧文 / DSH 插件市场 / 象上首页 / 本机历史片段；RSS 源可逐个开关、也能自己加，博客填自己的 RSS，天气填自己的城市和经纬度，留空就不启用；按日期种子随机排点（每天不同，不用固定钟点），工作日窗口内每天 N 条、间隔 ≥45 分钟；可试写、可手动发一条、可只试不写（dryRun）。设置页「发帖」里有块发帖数据：今天 / 最近 7 天 / 账本累计，按来源分布，最近一条的时间和链接。
- **历史片段**：从本机 DSH 存档（`session.v4.jsonl.zstd`）里挑真人说过的短句当素材；命中 IP / 路径 / 令牌 / 邮箱 / 手机号 / 内网关键词等隐私特征就整段丢弃，汇报式段落先洗成普通句子。按消息去重，不反复说同一段。
- **队列**：把旧管道里的「长毛象待发」（B 站内容）和历史记录收进来，每条错开 4–12 分钟慢慢发；入库前过隐私词，并把收过的内容记下来避免重复。
- **小本本**：本机 JSONL 记互动（谁、哪条、我说了什么、为什么没回），人物卡记「这个人是谁、聊过什么、雷区」，另有承诺清单。存储方式可选 `local` / `local+mnemon` / `off`。
- **暂停**：一键停掉「看通知、回嘟文」，不用卸载插件。

## 安装

从 npm 装（最省事，不用编译）：

```bash
dsh plugin --profile desktop add dsh-mastodon-toot
```

也可以直接装 GitHub Release 的预构建 tarball：

```bash
dsh plugin --profile desktop add https://github.com/meowdan/dsh-mastodon-toot/releases/download/v0.3.10/dsh-mastodon-toot-0.3.10.tgz
```

也可以从源码装：

```bash
dsh plugin --profile desktop add https://github.com/meowdan/dsh-mastodon-toot
```

npm 包名已占好 `dsh-mastodon-toot`，等 npm 账号就绪再正式发。

开发期用本地链接装：

```bash
dsh plugin --profile desktop add link:/path/to/dsh-mastodon-toot
```

装完重启 DSH（插件在宿主启动时加载）。然后到 **设置 → 长毛象** 填实例和令牌。

### 拿访问令牌

实例网页 → 首选项 → 开发 → 新建应用 → 勾选 `read`、`write`、`follow`（最少要 `read:notifications`、`read:statuses`、`write:statuses`）→ 复制「你的访问令牌」。

令牌只写到 `$DSH_HOME/mastodon-toot/credentials.json`，权限归当前用户；日志里只出现尾号。

## 设置项

| 项 | 默认 | 说明 |
|---|---|---|
| 自动回复 | 开 | 关掉就完全不看通知和时间线 |
| 主人 | 回 @ / 回时间线开；额度不限；每串 3；冷却 2 分钟 | 账号在「连接」测试后自动认出来，也可手填 |
| 好友（互关） | 回 @ / 回时间线开；每天 12；每串 2；冷却 10 分钟 | 我关注 ∩ 关注我，24 小时刷新一次 |
| 其他人 | 只回 @；每天 8；每串 1；冷却 15 分钟 | 陌生人时间线默认不插话 |
| 回复可见性 | unlisted | public / unlisted / private |
| 只看多少小时内 | 20 | 更旧的 @ 不补课 |
| 夜里安静 | 开 | 23:00–08:00 只回主人 |
| 小本本 | local | 只存本机 |
| 保留天数 | 180 | 超期清理 |
| 轮询秒数 | 30 | 通知增量轮询 |
| dryRun | 关 | 算出回复但只在日志里看，不发 |

### 发帖设置

| 项 | 默认 | 说明 |
|---|---|---|
| 自动发帖 | 关 | 打开后按当天随机排点发 |
| 每天最少 / 最多 | 7 / 10 | 按窗口与最短间隔自动收缩 |
| 最短间隔 | 45 分钟 | 两条之间至少隔这么久 |
| 错过仍发 | 120 分钟 | 晚到多久内还认这个点 |
| 时间窗 | 09:40–17:50 | 只在窗口内排点 |
| 只在工作日 | 开 | 周六日不排 |
| 素材开关 | 全开 | 天气 / 新闻 / GitHub / 博客 / 插件市场 / 对话 / 首页 |
| 博客 RSS | 空 | 你自己的博客 Feed；留空不启用 |
| 城市 / 经纬度 | 空 | 天气素材用；留空不启用 |
| RSS 源 | Solidot、IT之家 开 | 内置 6 个（Solidot / IT之家 / V2EX / HN / 阮一峰 / 少数派）逐个开关；另有自定义 RSS，一行一个，可写「名称|URL」 |
| 对话回看 | 24 小时 | 只从这段时间的会话里挑对话 |
| 首页回看 | 24 小时 | 只从这段时间的象上首页里挑 |
| 队列 | 开 | 收旧管道里的对话与 B 站内容 |
| 队列间隔 | 4–12 分钟 | 一条一条慢慢发 |

## 隐私

- 令牌、嘟文原文、人物卡都只在本机 `$DSH_HOME/mastodon-toot/`。
- 对话素材在本机读取、在本机过滤：命中隐私特征的整段不采用，也不上传到任何第三方；生成时走你自己在 DSH 里选的模型。
- 不会把嘟文内容发给本插件作者。
- 小本本可以一键关掉（`off`），关掉后不记任何互动内容。

## 开发

```bash
node --check index.js
node --check client.js
node scripts/smoke.mjs   # 用假 ctx 起 HTTP，走真实 token 测 /status /test /config
```

结构：

```
index.js          宿主：路由 + 心跳 + 状态
client.js         浏览器：设置页
lib/paths.mjs     家目录
lib/store.mjs     配置/凭证/状态/日志
lib/masto.mjs     Mastodon REST（含代理隧道）
lib/notebook.mjs  小本本：人物卡 / 互动流水 / 承诺
lib/sources.mjs   发帖素材：天气 / 新闻 / GitHub / 博客 / 插件市场 / 首页 / 队列
lib/chat.mjs      对话素材：读本机会话日志 + 隐私闸
lib/llm.mjs       走宿主模型
lib/compose.mjs   素材 → 提示词 → 正文
lib/posting.mjs   排期 / 发布 / 发帖账本 / 队列
lib/interact.mjs  互动引擎（v0.3）
```

## 更新记录

- **v0.3.13**：版本号只留一个来源。0.3.12 的日志和设置页还写死着 `0.3.11`（`index.js` 里的 `const VERSION` 忘了跟着改），现在改成从 `package.json` 读，以后改版本不会再对不上。行为没变。

- **v0.3.12**：改名「大肥鱼长毛象 bot」。README 标题、npm 描述、GitHub About、插件市场条目统一成这个名字，外加一句「自己发 toot、自己回嘟文，带一个小本本，记下聊过的人和话」。功能、配置项、数据文件一概不动，升级不用改任何设置。

- **v0.3.11**：修「别人直接 @ 我，我却一直不回」。通知游标里存的是**帖子 id**（18 位），而通知 id 只有 9 位——拿 18 位数去 `since_id=` 筛通知，永远筛不出东西，于是自 11-16 13:37 起所有直接 @ 我的通知都被静默吞掉；时间线那条路还通着，看着就像「有时候回、有时候不回」。现在游标只推进通知 id；启动时发现旧游标位数不对（>15 位）会自动清零重扫最近 20 小时，把吞掉的那几条补回来。

  另外加了发帖数据统计：设置页「发帖」里能看到今天、最近 7 天、账本累计各发了多少条，按来源（bili / conv / 天气+新闻…）分布，以及最近一条的时间和链接。数据直接从本机账本 `state/posted.json` 数，不额外维护计数。

- **v0.3.10**：修「同一条嘟文被发两遍」。13:46 旧 python 管道先发了一条（public），16:00 插件读同一份 B 站稿子又发了一遍（unlisted）——两套账互不知情。现在 doPost 发之前先拉我最近 40 条嘟文，把内容去空白、去链接后比对：完全相同或前 24 字相同就跳过并记账，不再发第二遍。设置页「队列」里加了「发前查重」开关（默认开）。

- **v0.3.9**：修「同一条嘟文被回两遍」。根因不在这个插件：旧的 python 监听器（Mastodon/poster.py stream）和旧队列（meowbot-toot-drain）一直还在跑，两套各自记自己的账，撞同一条就各回一句（一条 unlisted 一条 public，肉眼一看就是重了）。现在已经把旧管道停掉（STOP 文件 + 两个计划任务禁用），插件里再加一道保险：生成回复要花几秒，发之前重新拉一次上下文，发现我已经回过就不发。

- **v0.3.8**：修「别人回复我却不回」。三处根源：① 算「这串回过几次」时把我自己那篇被回复的原帖也算进去了，别人一回我就判定「这串回够了」；② 陌生人 @ 我卡在 15 分钟冷却里，而每轮扫完又把通知游标推到最新，被挡的那条永久丢掉；③ 时间线只认顶层帖，主人在串里说的话看不见。现在 @ 我的一律必回（绕冷却、夜里也回、额度×2），游标只推进到真处理完的那条，另外补了「主人自己发的帖」这一路。
- **v0.3.7**：修两处让「嘟文发不出去」的 bug——① 代理隧道里 tls 连接走错了对象，配了 HTTP 代理也照样自己去解析域名（直连被墙就整条链路挂死）；② 队列间隔把毫秒当分钟乘，一条条错开变成一条比一条远（最远排到一年后），现在新入队和旧队列都会把离谱时间拉回 4–12 分钟。
- **v0.3.6**：修设置页打字会跳回最上面。
